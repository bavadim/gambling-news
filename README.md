## Суть

**Заголовки против кассы** — русскоязычное медиа, которое сравнивает медийные нарративы с рыночными вероятностями Polymarket.

> Медиа могут пушить нарратив. Рынок может быть умнее, тупее или пьяным. Наша работа — показывать расхождение, не назначать святого.

Polymarket — **рыночный датчик ожиданий**: за какие сценарии люди готовы платить. РБК — ориентир русскоязычной деловой повестки: какие темы подаются как важные, вероятные, исторические.

## Что делает MVP

За 30–60 минут в день:

1. Выгрузить рынки Polymarket.
2. Выгрузить новости РБК.
3. Подобрать пару «новость ↔ рынок».
4. Посчитать индексы.
5. Опубликовать пост.

## Ограничения

- Не дает торговые рекомендации.
- Не публикует автоматические выводы без редактора.
- Не копирует полные тексты РБК.

## Индексы 

### Market Reliability

*Как оценить надежность рынка — просто:*

```text
reliability =
  0.35 * liquidity_score    # >$50k = 100, >$10k = 70, >$1k = 40, <$1k = 10
+ 0.30 * spread_score      # <1pp = 100, <3pp = 70, <5pp = 40, >5pp = 10
+ 0.20 * volume_score     # >$100k = 100, >$10k = 70, >$1k = 40, <$1k = 10
+ 0.15 * age_score        # <24h = 40, 1-7d = 70, >7d = 100
```

| Параметр | Хорошо | Плохо |
|----------|-------|-------|
| Ликвидность | >$50k | <$1k |
| Спред | <1% | >5% |
| Объем 24ч | >$100k | <$500 |

### ИРН (Индекс Реальности Новости)

Насколько рынок подтверждает медийный нарратив.

```text
market_support = (direction == YES) ? yes_prob : 100 - yes_prob
divergence = abs(media_claim - market_support)
IRN = clamp(100 - divergence, 0, 100)
```

- 70+: рынок подтверждает.
- 35–69: неопределенность.
- 0–34: рынок не верит.

### Confidence

Насколько можно доверять сравнению.

```text
Confidence = 0.4 * reliability + 0.4 * match_confidence + 0.2 * source_quality
```

Не публиковать если reliability < 50 или match_confidence < 60.

### Абсурдность

Насколько заголовок перегрет относительно рынка.

```text
absurdity = 0.5 * divergence + 0.3 * media_intensity + 0.2 * certainty
```

### Лудоиндекс

Насколько рынок похож на рациональный сигнал.

```text
ludo = 0.25 * liquidity_risk + 0.20 * spread_risk + 0.20 * move_risk + 0.15 * emotion + 0.10 * resolution + 0.10 * meme
```

- 70+: лудоразгон, осторожно.

## Рубрики

| Рубрика | Условие |
|----------|---------|
| Медиа пушит, рынок не верит | IRN < 40, Absurdity > 55 |
| Эксперт против кассы | Есть цитата, IRN < 50 |
| Рынок тоже идиот | LudoIndex >= 75 |
| Индекс Мрака | Mрак >= 70 |

## Операционный процесс

### Ежедневно

1. Запустить collectors → **polymarket_raw.csv** + **rbc_raw.csv**.
2. Выбрать 3–5 рынков из топа по volume/движению.
3. Найти связанные новости РБК.
4. Создать match → **match_queue.csv** → посчитать индексы.
5. Выбрать 1 пост → опубликовать.

### Еженедельно

- Индекс Мрака недели.
- Лудоразгон недели.
- Проверка прошлых постов («рынок тоже идиот»).

## Источники данных

### Polymarket

**API:** `gamma-api.polymarket.com` + `clob.polymarket.com`

**Endpoints:**

```text
GET https://gamma-api.polymarket.com/events?active=true&closed=false&order=volume_24hr&limit=100
GET https://clob.polymarket.com/prices-history?market={asset_id}&startTs={unix}&endTs={unix}
```

**Проблемы:**
- CORS заблокирован в браузере → нужен прокси или серверный скрипт
- Требуется 2 запроса: events → markets → prices

**Шаблон:** `templates/polymarket_raw.csv` (31 поле)

### РБК

**API:** RSS

**URL:** `https://rssexport.rbc.ru/rbcnews/news/30/full.rss`

**Проблемы:**
- RSS может не включать полный текст → только заголовок + краткое описание
- Telegram канал требует Telethon (отдельный скрипт)

**Шаблон:** `templates/rbc_raw.csv` (21 поле)

### Исторические цены (для дельт)

**API:** тот же CLOB

```text
POST https://clob.polymarket.com/batch-prices-history
```

**Проблемы:**
- Дельты считаются вручную или отдельным скриптом

**Шаблон:** `templates/computed_prices.csv`
